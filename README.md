# 💰 Expense Splitter

A simple and user-friendly Expense Splitter web application built using HTML, CSS, and JavaScript.

Expense Splitter helps users manage shared expenses, track who paid for what, and make splitting expenses easier.

## 🚀 Features

- Add and manage shared expenses.
- Enter the expense amount and description.
- Select who paid for an expense.
- Remove expenses when needed.
- Calculate and manage expense splits.
- Simple and user-friendly interface.
- Responsive design.

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript

1. Clone this repository:

   ```bash
   git clone YOUR_REPOSITORY_URL
   ```

2. Open the project folder in VS Code.

3. Open `index.html` in your browser.

4. Start managing your shared expenses!
